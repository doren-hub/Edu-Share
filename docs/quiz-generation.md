# クイズ生成の応答契約

Claude の出題では `submit_quiz` ツールを `tool_choice` で指定し、`questions` 配列を受け取る。`src/lib/quiz-output-schema.ts` の Zod スキーマから `input_schema` を生成し、受信後も同じスキーマで各設問を検証する。

- ID・設問・選択肢は空白のみを認めない。選択式は4択、正解は0〜3の整数とする。不正な正解番号を丸めて採用しない。
- 不正な設問、重複ID、教材本文と照合できない根拠抜粋は除外する。抜粋に対応するPDFページの付与を維持する。
- 少数・空の設問配列も返す。既存のAPIが過去セッションから不足を補う方針を維持する。
- ツール応答がある場合はそれを優先する。名前の不一致、複数呼び出し、`questions` 配列の欠落はエラーとし、同時に返されたテキストでは救済しない。
- Gemini とツールのない旧形式応答ではテキスト配列を解析する。通常の JSON 解析を先に試し、失敗した場合のみ `jsonrepair` 等の修復を使う。この経路にも同じ設問検証を適用する。

記述式の採点は従来のテキスト応答を使い、出題ツールは送信しない。テストは偽APIクライアント・偽fetchを使い、実キーや外部APIを必要としない。
