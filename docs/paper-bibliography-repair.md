# 対象を限定した論文書誌の修正（Issue #116）

## 対象と確認状況

対象は `agronomy-09-00403.pdf` の登録 **1 件**。公開された[出版社の書誌](https://www.mdpi.com/2073-4395/9/7/403)は次のとおりです。

- 題名: AgROS: A Robot Operating System Based Emulation Tool for Agricultural Robotics
- 掲載誌: Agronomy
- 年: 2019
- DOI: `10.3390/agronomy9070403`

Issue で報告された短い題名、著者 `DOI`、掲載先 `journal` は検証対象です。この開発では対象原本・登録ログが作業木に存在せず、実登録の内容は未確認です。公開書誌の検索結果は確認しましたが、出版社ページ本体は一時的に HTTP 429 でした。著者一覧は必ず所有者の原本と出版社書誌で確認してください。推測した人名は登録しません。

## 所有者が通常アプリから実施する手順

1. Edu Share の通常画面で対象をファイル名から探し、登録済み原本を開く。ファイル名に加えて DOI と題名冒頭を照合し、同名・類似タイトルの別登録を選ばない。候補を一意に特定できなければ更新しない。
2. 対象の資料情報（題名・著者・掲載・年・DOI）を個別に控える。原本およびスライド・動画・クイズ・単語帳の既存添付があることも確認する。私的な登録 URL、原本本文、個人パスを公開 Issue に転載しない。
3. 原本の先頭ページと出版社の書誌を照合する。改行された題名を全文として確認し、著者の全員・順序・綴りも確認する。照合不能ならその項目は現在値を保持する。
4. 対象登録の「資料情報」→「編集する」から、確認できた誤りだけを直す。題名は上記全文、掲載先は `Agronomy` とし、年・DOI が既に正しければ維持する。著者 `DOI` は確認した実際の著者一覧に置換し、`DOI` / `journal` を著者選択肢として新規登録しない。SciSpace の汚れたコピーをそのまま貼り直さない。
5. 通常の保存操作後にページを再表示し、全文の題名と確認した各書誌項目、既存の四種類の教材と原本が保持されていることを確認する。必要なら同じ画面の編集から控えた値を戻す。
6. 対象 1 件の結果のみを Issue に記録する。他の既存登録は、著者名が掲載に入ったという印象だけで変更しない。別の対象を確認した場合も、原本との個別照合と別途の対象指定を先に行う。

SQL、DB / R2 の直接操作、一括変更、原本・添付の削除、マイグレーション適用は行いません。この作業では上記手順の実行自体を行っていません。

## 自動処理の検証と保留

- 著者行がなく掲載先を裏付けられないカードでは、残り行から掲載先を推測しない。明示的な誌名のヒントがある行は引き続き使える。
- 単独の UI ラベルは著者・掲載先の値に採用しない。掲載先が同じカードの著者名と一致する場合も除外する。
- 既存 DOI も自動では上書きしない。誤った DOI の修正は上記の対象限定手順で原本と照合して行う。
- 保存済みの完全な題名・有効な掲載先を、未確認のカード値で上書きしない。反映用の貼り付け文と API の項目選定にもこの制約を適用する。題名を送らない場合の掲載は年-掲載形式にし、著者を確認できない場合は掲載も貼り付けから除いて、アプリの推測による別項目への読み替えを防ぐ。Files 原文は診断用に保持する。
- 原本 PDF の DOI と Crossref の DOI が一致し、完全題名も原本冒頭のテキストに連続して現れ、候補がその題名と一致または先頭部分である場合にだけ完全題名を補完する。Crossref の障害・別 DOI・原本と不一致の応答では補完しない。
- 省略記号、原本内の長い題名の先頭部分、明らかな次行への継続を検出した場合、照合できるまで題名の反映を止める。スキャン、文字抽出失敗、複雑な組版やハイフン分割で確認できない場合は人が原本で照合する。既存の正しい項目を推測で置換しない。

回帰テストはネットワーク不要の原本テキストと公式応答の fixture を使います。実 NotebookLM / SciSpace / Edu Share や本番 DB / R2 には接続しません。`tools/paper-pipeline` 内で `node --import tsx --test src/scispace-card.test.ts src/steps/scispace.test.ts src/crossref.test.ts` と `npm run typecheck` を実行できます。
